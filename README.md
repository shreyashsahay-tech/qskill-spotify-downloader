# Spotify MP3 Downloader

A beginner-friendly web application developed for the QSkill Internship Basic Web Development task.

## Features

- Spotify track URL validation
- Simple and responsive user interface
- JavaScript-based input validation
- Displays song title, artist and duration
- MP3 download functionality
- Node.js and Express backend
- Downloadable sample MP3 file
- Spotify-style dark theme

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js

## How to Run

How to Run
1. Install Node.js
Make sure Node.js is installed on your computer.
2. Open the project folder in VS Code
Open the QSkill-Spotify-Downloader folder in VS Code.
3. Open the terminal
Open the VS Code terminal in the project folder.
4. Install dependencies
npm install

5. Start the server
node server.js

6. Open the application
Open the following address in your browser:
http://localhost:3000

7. Use the application
Enter a Spotify track URL and click Download.
Note
The application uses a legally provided sample MP3 for the download demonstration. The Spotify URL is used for input validation and demonstration of the application workflow.
